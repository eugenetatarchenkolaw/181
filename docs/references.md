# Источники и основания решений

[Вернуться к проекту](../README.md)

Актуализировано 02.10.2026. Здесь перечислены первичные публикации и официальные описания инструментов. Это начальный список для реализации и обзора, а не завершённый анализ всей литературы. Параметры API и доступные модели проверяются повторно перед соответствующим запуском.

## Поиск и сбор данных

| Источник | Для чего используется в проекте |
|---|---|
| [Sentence Transformers: Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html) | Разделение быстрого получения кандидатов и совместной оценки пар вопрос–фрагмент через cross-encoder |
| [GROBID: REST API](https://grobid.readthedocs.io/en/latest/Grobid-service/) | Извлечение библиографии и структурированного текста PDF; сохранение исходных записей через `includeRawCitations` |
| [Crossref: REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | Получение и уточнение метаданных; библиографическая запись не равна доступному полному тексту |
| [arXiv: API User Manual](https://info.arxiv.org/help/api/user-manual.html) | Идентификаторы, версии и метаданные препринтов |
| [Unpaywall: Data Format](https://unpaywall.org/data-format) | Открытые размещения по DOI; поля `best_oa_location` и `url_for_pdf` могут отсутствовать |
| [arXiv: License Information](https://info.arxiv.org/help/license/index.html) | Проверка лицензии конкретной версии перед распространением корпуса |
| [OpenRouter: Limits](https://openrouter.ai/docs/api/reference/limits) | Учёт квот, ошибок ограничения запросов и условий бесплатного доступа |

Выбор комбинации BM25, bi-encoder и cross-encoder — инженерное решение проекта. Его пригодность для собранных данных предстоит измерить; документация библиотек не доказывает будущий прирост качества.

## Научные ориентиры

| Работа | Что важно проверить при обзоре |
|---|---|
| Dasigi et al., [A Dataset of Information-Seeking Questions and Answers Anchored in Research Papers — QASPER](https://arxiv.org/abs/2105.03011), 2021 | Как связаны вопрос, ответ и поддерживающий фрагмент; чем информационные вопросы читателей отличаются от вопросов, сгенерированных по известному ответу |
| Skarlinski et al., [Language agents achieve superhuman synthesis of scientific knowledge — PaperQA2](https://arxiv.org/abs/2409.13740), 2024 | Поиск и синтез научной литературы, проверка ответов и устройство оценки; название статьи не переносится в обещания нашего проекта |
| [OpenScholar: Synthesizing Scientific Literature with Retrieval-augmented LMs](https://arxiv.org/abs/2411.14199), 2024 | Работа с научным корпусом и синтез с источниками; какие части задачи уже решались и где возможен отдельный исследовательский вопрос |

Перед заявлением новизны обзор расширяется актуальными работами по междокументному QA, retrieval и оценке цитирования. Для каждой фиксируются данные, доступность кода, базовые методы, метрики и ограничения сравнения. Отдельно следует проверить работы о визуальном поиске по документам, если выбрано CV-расширение.

## Как пользоваться списком

Для второго чекпойнта сначала нужны документация по библиографии и загрузке, затем правила доказательной разметки. Перед этапами 3–6 читаются источники о соответствующем методе поиска и выбираются конкретные реализации. Перед отдельным исследованием составляется таблица ближайших работ; само наличие этих ссылок в репозитории не означает, что обзор или эксперименты выполнены.
